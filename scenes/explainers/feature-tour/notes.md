# Feature tour notes

The starting copies, camera ruler and Restore example’s dashed outline are explanatory artwork added by this scene. They are not produced by the displayed recipe lines. Keeping that distinction visible prevents readers from attributing the before-and-after presentation to Transform itself.

The camera changes the whole view, which is why its result uses a ruler instead of parallel before-and-after panels. The glyph correspondence under the matching example comes from the actual matched pairs.

The fifteen cases are short demonstrations rather than complete API coverage. The direction example uses Latin text in a right-to-left layout; it does not demonstrate shaping a right-to-left script. Changing the feature returns to its recipe, while a direct result permalink remains supported.
