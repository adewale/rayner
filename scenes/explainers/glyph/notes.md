# Glyph notes

The measurements use the bundled Inter and JetBrains Mono faces, at size 0.9 for the opening. The phrase has fifteen characters but fourteen drawn glyphs because the space has no outline. The shape-match result concerns this phrase and these font files; it is not a claim that no glyphs in any two fonts can match.

The matching comparison removes translation and uniform scale, not differences in the paths themselves. The diagram example deliberately retains recorded layout widths; font-metrics supplies the contrasting case where the chosen face is measured before layout.

The construction uses the engine’s shaped runs and outline paths rather than estimated character widths.
