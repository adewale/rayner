# What does a WCAG conformance level require?

Press Tab to move through two buttons, Cancel and Pay. Without a visible focus indicator, you cannot see which button will activate. In the second drawing, an outline marks Pay. That is the kind of keyboard experience addressed by Focus Visible, a level AA success criterion.

Does aiming for AA mean checking only the criteria labeled AA? No. The levels accumulate: AA includes A as well as AA, and AAA includes all three levels. Selecting a level changes the set of criteria in the map, not just the label on an otherwise fixed checklist.

The WCAG version matters too. Start with 2.0's criteria, then add the ones introduced in 2.1. Version 2.2 adds more and removes 4.1.1 Parsing. Counting that removal matters: a newer version is not simply every older requirement plus some new ones.

Open a guideline to inspect the criteria behind its total. Each criterion names its level and the version that introduced it. The removed Parsing criterion stays visible as history but no longer contributes to the 2.2 count. Focus Visible remains AA in the final 2.2 text, even though some earlier drafts proposed moving it to A.

The map helps identify which published requirements belong to the chosen version and level. It does not test a page. Counts cannot establish conformance: the applicable criteria, their conditions and exceptions, and the requirements for complete pages and processes still need to be evaluated. A policy that names an older WCAG version also needs to be distinguished from the current version shown.
