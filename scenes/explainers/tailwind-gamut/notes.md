# Construction and scope

The raw and relative views answer different questions. Each radar spoke uses its colour's own lightness and hue; equal angular spacing is a family index, not a uniform hue scale. The relative view starts at 50%, so its distances should not be read as raw chroma. The opening compares against sRGB even when the selected ending is Display P3.

The model uses the 300, 500 and 700 shades of seventeen coloured families from Tailwind 4.3.3; it omits the grey families. The script's named values are the default shade-500 scenario. Gamut edges and mapped colours are different calculations: the mapping uses binary search with Local MINDE followed by clipping, which can shift hue. It models the pinned CSS algorithm, not a measurement of a reader's screen, calibration, colour management or a particular browser's mapping implementation. Results are compared with Color.js 0.7.1.

Sources: [pinned Tailwind theme](https://github.com/tailwindlabs/tailwindcss/blob/c2b24dd15fed1c59dd521bd86082f520c9f5ad0d/packages/tailwindcss/theme.css), [v4 announcement](https://github.com/tailwindlabs/tailwindcss.com/blob/7f92c2213315c195dae583d68752da4042da3ade/src/blog/tailwindcss-v4/index.mdx), and [pinned CSS Color 4 code and mapping specification](https://github.com/w3c/csswg-drafts/tree/e1bd39185acd650512f82e1eeb7b94da21b686c7/css-color-4). Exact conversions are cited in `../lib/tailwind-gamut.ts`.
