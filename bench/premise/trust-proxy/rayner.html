Which address should Express call the client?

Requests are meant to reach Express through a CDN and then a load balancer, so every connection Express sees comes from the load balancer, 10.0.0.5. Express’s req.ip should still name the machine that sent the request. Setting trust proxy to 2 tells Express that two proxies stand in front of it; the path through the CDN has two. But the load balancer also accepts connections from the internet, so an attacker can skip the CDN. Here an attacker skips the CDN: will req.ip be the attacker’s real address, 198.51.100.9? All the addresses are examples.

  1. The attacker skips the CDN again, but writes two made-up entries: X-Forwarded-For: 5.6.7.8, 1.2.3.4. Which address becomes req.ip with trust proxy 2, and which with true?

    Show the answer

  3. What must hold for the address list '10.0.0.0/8, 192.0.2.0/24' to keep req.ip right?

    Show the answer

    Every trusted range must hold only your own proxies. The list trusts machines by address, not positions, so path length no longer matters, but an attacker inside a trusted range would be skipped like a proxy.
