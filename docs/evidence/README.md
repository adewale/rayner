# Evidence

Current development screenshots and validation receipts belong under `out/` and in CI artifacts. Commit a small example when it helps review a visible change.

Earlier player designs, screenshots and dated audit reports are preserved in [Git history at ce11e0a](https://github.com/adewale/rayner/tree/ce11e0ac611cc7b4babc24a573039ef96f179c3f/docs/evidence). They describe those revisions, not the current player. Their explainer scores (out of 24, and later 28) use the editorial rubric's retired 0–4 scale; the current [Judging an explainer](../EXPLAINER-RUBRIC.md) gives no scores to compare them with.

This directory retains release records, upstream backport findings, independent lettering vectors, test-oracle notes and measured benchmark results. Diagram and lettering snapshots beside the scenes are build inputs; they are not audit reports.
