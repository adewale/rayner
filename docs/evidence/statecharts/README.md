# Statecharts: decisions

Based on David Khourshid's [Statecharts in 2 minutes](https://x.com/DavidKPiano/status/2116523008323981315). The explainer shows the approved script in [`script.md`](../../../scenes/explainers/statecharts/script.md); each step names the script sentences it shows.

- **Script first.** Two earlier versions were built from a model and a rubric and never said what a statechart is. The script answers the reader's three questions in four paragraphs, and the steps follow it in order. The definition is the first caption, and `meta.answer` holds `check` to stating it.
- **Two examples, one idea each.** The coffee machine shows a parent state (one POWER_OFF instead of four); the media player shows regions (and the boolean bug they remove). A milk frother added to the coffee machine is the transfer case.
- **Questions the reader answers.** Steps 2, 4, 6, 7 and 9 ask a question in their lines and the next step answers it; the rail hides each answer step's title until it is reached. The script's three check questions are in `meta.checks`, asked after the last step.
- **Native drawing from the model.** Every box and arrow is a model state or transition, and parts keep their keys across steps, so the grid's own words move into the regions. A Mermaid state diagram now handles composites and regions ([recipe](../../REFERENCE.md#state-machines-and-graphs)), but it cannot yet add a region by a verified edit, and the frother chart does not fit the stage at a readable size, so the scene stays native. XState 5.33.3 is run on every drawn chart (`tools/oracle/statecharts.ts`).
- **Against a hand-made page.** In the [explainer benchmark](../../../bench/explainers/README.md), pages the same models wrote without Rayner were preferred in both rounds, because their readers drive a live machine; [#88](https://github.com/adewale/rayner/issues/88) proposes that for Rayner.
- **Limits.** The model covers compound and parallel states with event transitions only. A model reader answered the check questions from the explainer, but a control reader answered them without it, so they do not show what the explainer teaches; no person new to statecharts has tried it. No subject expert has reviewed the scene.
