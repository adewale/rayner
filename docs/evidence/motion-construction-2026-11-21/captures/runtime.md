## Construction matrix across Rayner

“By construction” is useful when a representation can exclude a specific invalid state. It cannot establish that the model describes the intended domain, that a caption makes the right promise, or that a route tells the intended story. The smallest useful units are existing boundaries, not a second authoring framework.

## Native ownership integration follow-up

The root's complete Refusals integration exposed synchronous Resvg native retention after the earlier failing assertions no longer stopped the workload. I reproduced failure with `NODE_OPTIONS=--max-old-space-size=1024` and `--test-concurrency=1`: the first test passed, then the worker failed at **67.24 seconds** (`refusals-resource-before.log`). The observed RSS was **3,075,940 KiB** after 19 seconds; this is an observed lower bound, not the unavailable final peak or a completed render inventory.

The route helper now passes immutable SVG strings to the supported `renderAsync` API and awaits each native task. Temporary knockout/tint mutations are restored synchronously before rendering yields. The `without` callback's type admits only a string or a readonly string array, so a Promise cannot accidentally prolong a temporary mutation. Every caller, including poison fixtures that restore traveller positions, awaits `frame` before proceeding. No GC hooks, opacity/overlap suppressions, reduced frame sampling or heap-limit workaround were introduced. `src/`, `explain/` and `tools/lib/` stayed frozen throughout this follow-up.

The new keeper (now `test/route-ink-await.test.ts`, moved behind the repository boundary in the portable follow-up below) derives the helper's transitive importer graph from the Node source inventory, then resolves the actual method declaration for calls in those importers. At the async-migration checkpoint it found **53 calls** across **12 clients**, required each call to be awaited, then removed one real await and parenthesized its callee in an in-memory compiler host: the complete call inventory remained the same and exactly one detached call was detected. This handles nested check objects, maps, conditional selections, indirect call syntax and the standalone proof tool without maintaining a second filename list. Resolving only actual importers also avoids instantiating every unrelated generic call across the repository. The keeper passes under the same 1 GiB heap guard. TypeScript accepts an ignored Promise without this boundary check.

## Remaining limits

No reviewed runtime counterexample remains reproduced by these focused controls. This does not certify every possible SVG or transition. Conservative geometry still abstains on unsupported paints, partially clipped glyphs and ambiguous multi-mask/curve intersections. Changed overlapping foreground paint may make genuine travel unproved; the diagnostic says exactly that. Native samples are finite, and browser CSS, text shaping delivery and reader transport retain their real-browser owners. A whole-picture fade now obeys the existing leaf-opacity renderer; it does not introduce inherited SVG group opacity semantics.

Wrapper correspondence is inferred only when surviving descendants establish a unique correspondence. General arbitrary hierarchy changes and continuous interpolation of changing retained-owner viewports are not solved by guessing; authored transitions and the ordered native endpoint proof remain their boundary. Scene-specific source ownership, promised domain content, allowed endpoint attachments, reading duration and offered exercise reachability still need the independent chapter evidence owned by the root. These repairs do not alter the historical corpus score or retrospectively relabel historical visual evidence.
