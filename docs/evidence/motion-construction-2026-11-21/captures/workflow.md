# Workflow construction review and repairs

Agent 2 scope: shared exploration, film, served-review planning, receipt identity, corpus execution/scoring, and an adversarial construction matrix across Rayner. Reviewed the seven `out/adversarial-astra/*.md` reports and `test/AGENTS.md`. Runtime and chapter changes are owned by the other agent and root; this report does not claim their validation as mine.

## Judgment

Rayner can make many structural defects impossible at the point where they enter: invalid JSON, illegal event names, ambiguous ownership, inconsistent schedules, unreachable replay logs, incomplete evidence inventories, and publication of unfinished output. It cannot construct narrative truth or human readability from a TypeScript type alone. The strongest design is one authority for each mechanism, plus a genuinely independent observation for the consequence that mechanism promises.

In particular, model identity is not picture identity. A finite model may have several incoming responses and several distinct pictures from which the next event starts. Collapsing these into a durable-state walk was a shared workflow correctness failure, not an absent scene-specific assertion.

## Implemented

- Added `tools/lib/explain-picture-inventory.ts`, shared by checker, film, and served-review planning. Durable exploration is bounded per root. Each accepted model edge computes its transient result once during enumeration. Parent links retain representative legal histories; state-plus-presentation identity deduplicates before scheduling picture checks. Accepted, refused and beyond edges are retained; completeness remains explicit.
- The checker retains both model-start and actual offered-root contexts. Film and served review use only the actual `runLive`/`logStart` reader origin. Film visits every admitted presentation/press pair. Served review requires every distinct immediate response, including a result cleared back to the opening, then samples deeper presentations and the farthest one.
- Check reports now distinguish durable states, presentations, tested accepted transitions and model observations. The CLI says **checked states** and explicitly marks a bounded sample. Film manifests include root, state/presentation/press counts and completeness.
- Film writes into a uniquely allocated owned generation. Publication is serialized with an exclusive directory lock. Every frame exists before the manifest is atomically renamed as the commit point. A failed render removes only its unpublished generation and preserves the previous manifest, HTML and frames. Successful replacement retires only frame paths listed by the previous manifest; unrelated files remain untouched.
- Source review receipts now fingerprint the transitive runtime import closure from review/check entry points, reusing the page producer's import walker. Static imports, re-exports and literal dynamic imports are followed; type-only imports are excluded. Installed tools still fingerprint their bundled output. This is evidence freshness identity, not a behavior snapshot tied to Rayner's code hash.
- Corpus findings now carry structured observation fields. Keyed native findings retain actual victim/text/mask attribution supplied by the runtime agent. Motion contract subjects and requirements are normalized at collection. Refusals retain exception name, category, message and duration-event identity.
- Baseline identity retains the victim and foreground mask for ordinary covers as well as occluded words. Exact `expectedFinding` and `expectedRefusal` targets are applied through subtraction and scoring. `caught` is a derived display field, never scoring authority.
- Workers must exit successfully, without a signal, and return a valid schema with the requested identity. Runs distinguish complete replay, typed early refusal and errors. Missing/duplicate variant or baseline inventories fail. Workers have a 2 GiB JS heap bound, a 20-minute timeout and a 64 MiB stdout ceiling; default concurrency is two.
- Findings are emitted before a later reader transition can abort the whole exploration. An ordinary abort preserves prior observations with an error and no score; a typed guard records those earlier observations alongside the refusal. An incomplete baseline cannot establish freshness.
- The summary separately reports any rejection, explicitly attributed findings, declared refusals, guard-only cases, warnings without attribution, and exact-target matches. These are overlapping evidence categories, not additive buckets. The historical 41/59 remains historical; the corrected current score must be remeasured by root.

## Cost and benefit

`workflow-cost.json` reruns the exact `cost()` function and 32/64/128/256-state inputs from the archived adversarial probe. Animation selection is empty, so these numbers isolate enumeration rather than renderer cost.

| Durable states | Accepted edges | Before result calls | After result calls | Before model calls | After model calls |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 32 | 31 | 2,480 | 31 | 2,577 | 33 |
| 64 | 63 | 10,080 | 63 | 10,273 | 65 |
| 128 | 127 | 40,640 | 127 | 41,025 | 129 |
| 256 | 255 | 163,200 | 255 | 163,969 | 257 |

The largest workload eliminates 99.84% of result evaluations (640-fold fewer). Its new observed elapsed time was 12 ms versus the archive's 219 ms. The archive and current process conditions are not a controlled timing experiment, so the callback counts support the claim; the elapsed values do not establish a general speedup. The no-result workload still makes the same 257 model calls and now materializes explicit edges, so it has some small extra bookkeeping (11 ms versus archived 5 ms in this run). Actual transition replay still evaluates the author's callbacks as required by the public playback path.

Film now spends more work on previously omitted distinct presentation edges. That is necessary coverage, bounded by admitted states, event count and incoming responses. Served browser work remains sampled beyond the immediate responses. The private generation temporarily requires disk space for both the old and new successful outputs. Transitive fingerprints invalidate receipts on helper changes, which costs re-review but prevents stale evidence reuse.

## Measurement follow-up: UTF-8 worker transport

The frozen capture exposed a process-boundary defect: `runInChild` concatenated individual stdout Buffers as strings. A multibyte quote split between pipe chunks can become replacement characters in just one of the identical `findings`/`fresh` copies. The exact membership guard correctly rejected the corrupted result while retaining 352 observations, but discarded the corrupted `fresh` copy. This was transport loss, not a scorer mutation.

A cheap real-pipe reproduction using one retained finding produced the exact rejection. Streaming UTF-8 decoding made the same payload pass unchanged. With root authorization, the production repair added only `child.stdout.setEncoding('utf8')` and `child.stderr.setEncoding('utf8')` before the data listeners. Process exit, typed schema, expected identity and fresh-membership guards remain intact. Normalizing redundant fields would have hidden the symptom without preserving Unicode in other observations, so the transport was repaired directly.

The new end-to-end regression forces the split with a child/parent stdin handshake, without scheduler timing assumptions. It verifies an exit-zero result exactly and verifies that exit 17 preserves observations and the split stderr diagnostic while receiving no credit. The complete corpus report owner passed **13/13, zero skips**; see [worker-unicode-owner.log](./worker-unicode-owner.log). The pre-repair counterexample is retained in [worker-unicode-repro.json](./worker-unicode-repro.json). No expensive corpus worker rerun was needed to identify or test the mechanism. Root owns fingerprint provenance, the transport-only processing amendment and rerunning the affected/remaining measurements.

## Remaining limits

The inventory assumes the declared pure model/result contract; it cannot discover hidden closure state. It checks bounded durable graphs and their distinct incoming presentations, not every arbitrary event history. Film coverage is native sample footage, not continuous-time or browser-layout proof. Deeper served paths remain sampled. The fixed-width native oracle does not prove every font, viewport or backend.

The source import closure follows literal local imports. Dynamic data/files that are not imports still need the existing explicit build-input/companion inventories. A hard crash can leave a film publication lock or an orphan generation; current code deliberately preserves data rather than guessing which tree is disposable. Film's manifest is the atomic authority; HTML and manifest are separate files, each referring only to fully rendered data.

The corpus still contains historical cases without predeclared exact subject targets, and its legacy rejection metric remains broad for those cases. This repair does not retroactively invent their targets. Typed guard-only rejections establish prevention of execution, not filmed proof of the named visual defect. Root owns the new complete 59-variant/eight-baseline measurement, the scene-owned prevention count, and the honest comparison with the old 41/59.
