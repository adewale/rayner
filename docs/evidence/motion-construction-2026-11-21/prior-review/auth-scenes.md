# PR 115 review of the four credential scenes

The PR introduces two visible regressions in ordinary playback. The first Browser fetch removes an unchanged empty-rack label for 47 frames. Collecting a SignIn key now erases the end of “your agent” in both sign-in layouts. Three further presentation defects reproduce on both the PR and main. Independent controls also demonstrate a false alarm and a missed physical duplicate in the new Sessions checks.

I compared head `bad42099793aba0988fc98a6daaf3819f3bf4559`, PR base `11b9ab5a61fbed0cb57006f583317b56eb02b5aa`, and main `2bab6486b8f33bf1238b3f239ee9ed7b357bc66b`. I reviewed the 35 frozen IDs and their Sol dispositions. Native measurements below use Resvg with the repository’s shaped glyphs. For collisions I rendered each complete frame, then removed the traveller, the label, and both independently. Counts identify label pixels that contributed more than 16 RGB levels without the traveller and at most 15% of that contribution with it. All retained 358-pixel images were originally rendered at that width.
