The package contains 59 primary comparisons and 23 additional route comparisons. All primary videos preserve the 30 fps scene clock. Each linked browser pair shows native 800 × 450 frames side by side. The three phone pairs show each picture at 358 pixels wide. A rejected transition shows only its pre-event picture. Cases with multiple observed effects identify which part of the historical claim the frames establish.

The current baseline also has visible defects. In the password route both versions cover scope text, with a larger obstruction in the reconstruction. The fixed device poll grazes the end of the company name at a later offset. The evidence records those baseline contacts alongside the stronger reconstructed contact.

The machine-readable report contains the exact historical claim, step caption, settings, event history, before/after states, frame intervals, native receipt paths, pixel-removal measurements and supplemental visual evidence for every entry. Negative verdicts are scoped to the examined routes, except the exhaustive comparison of both edited glyph transitions. ## Reproduce a comparison

Use the baseline source commit above with the audit helpers available in the checkout. The corpus variant builds in an isolated directory under `out/`. The capture uses the project’s normal scene loader and public reader replay.

```sh
node tools/repo/motion-audit-capture.ts sign-in-poll-over-card
```

Each resulting `baseline/` and `variant/` directory holds the original numbered SVGs, corresponding Resvg PNGs and its frame receipt. For an alternative route, pass the exact route JSON as argument two and its output suffix as argument three. The two sides of a rejected transition stop at different times.

```sh
node tools/repo/motion-audit-browser.mjs --input out/motion-all59-audit/sign-in-poll-over-card/variant --frames 27-30 --out out/poll-browser
```

The browser helper verifies the Playwright revision and actual binary version. Set `PLAYWRIGHT_BROWSERS_PATH` to the directory containing the pinned browser, or use the prepared `/tmp/rayner-pinned` installation. Add `--phone` to paint at the recorded phone width. To repeat a knockout, extract the selected capture’s `queries` array from the measurements archive and run `node tools/repo/motion-audit-measure.ts <capture-directory> <queries.json>`.

Videos retain complete painted event intervals, including uneventful frames. The glyph video shows the first 37 frames of each affected step. The receipt archive includes all 1,564 frames of those two steps. An outlined path can be present in source geometry and still contribute no visible ink. The knockout measures the rendered contribution.
